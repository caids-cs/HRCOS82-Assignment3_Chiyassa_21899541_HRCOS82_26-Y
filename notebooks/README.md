# Notebooks

Notebooks are for **exploration only** — looking at distributions, sanity-checking a
join, trying an idea.

Anything that produces a number, table or figure for your write-up belongs in
`src/` and must run from `python run.py`. Results that exist only inside a notebook
cannot be reproduced, and a result that cannot be reproduced is not a result.

Notebooks are committed, but clear the outputs before you commit (Kernel → Restart
and Clear Output). Stored outputs make the file enormous and can accidentally carry
data into the repository.
